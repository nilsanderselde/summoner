# Summoner Open Source Foundation Governance

## Overview
The Summoner Open Source Foundation is committed to maintaining Summoner DAW as an open, deterministic, high-performance audio engine licensed under AGPLv3.

## Roles & Responsibilities
- **Maintainers**: Core contributors with commit access responsible for code review, release tag signing, and architectural stewardship.
- **Contributors**: Community members submitting pull requests, bug reports, documentation enhancements, and third-party Lua device scripts.
- **Steering Committee**: Elected representatives governing project roadmap priorities and technical steering.

## Decision Making Process
Decisions are made by consensus among maintainers. Major architectural changes require a formal RFC (Request for Comments) submission in `docs/rfcs/` with a minimum 14-day discussion period.
